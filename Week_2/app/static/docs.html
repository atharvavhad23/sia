⚙️ Extraction Engines
⚡
Fast Engine
engine=fast
Powered by PyMuPDF (C-based). Blazing fast raw text and metadata extraction. No table support.
~0.2s on financial reports
🔍
Structural Engine
engine=structural
Powered by pdfplumber. Preserves layout and structure. Good table support. Slower on large files.
~6.5s on financial reports
🚀
Hybrid Engine
engine=hybrid
Camelot for precise table extraction + PyMuPDF for fast text. Best accuracy-to-speed ratio.
~2.7s on financial reports

POST /api/v1/extract Extract text, tables, and metadata from a PDF

Upload a PDF document and choose your processing pipeline. Returns structured text and table data in JSON or Markdown format.

Parameter Type Required Default Description
file file REQUIRED — The PDF document to process
engine string OPTIONAL hybrid Processing engine: fast, structural, hybrid
output_format string OPTIONAL json Response format: json or markdown 
curl -X POST "http://127.0.0.1:8000/api/v1/extract" \
  -F "engine=hybrid" \
  -F "output_format=json" \
  -F "file=@financial_report.pdf"
import requests

with open("financial_report.pdf", "rb") as f:
    response = requests.post(
        "http://127.0.0.1:8000/api/v1/extract",
        data={"engine": "hybrid", "output_format": "json"},
        files={"file": f}
    )

data = response.json()
print(data["data"]["metadata"])
print(data["data"]["tables"])

🛡️ Error Reference

      

        

          200
          Extraction completed successfully
          Returns extracted data in JSON or Markdown
        

        

          400
          Only PDF files are supported
          Uploaded file is not a .pdf
        

        

          400
          Password-protected PDF
          PDF is encrypted and cannot be read without a password
        

        

          400
          Corrupted or unreadable PDF
          File is not a valid PDF or is corrupted
        

        

          400
          Invalid engine or output_format value
          Parameter value is not one of the allowed options
        

        

          500
          Internal Server Error during extraction
          Unexpected backend failure; check server logs
