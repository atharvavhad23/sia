✨ Powered by LanceDB + Gemini · Streaming enabled

REST API Endpoints

Production endpoints for microservice integration. Base URL: http://localhost:8000

GET / Health Check

Returns service operational status.

curl http://localhost:8000/
POST /api/v1/ingest RAG Vector Ingestion

Runs the full 5-stage pipeline: Parse → Chunk → Embed → Metadata → LanceDB.

curl -X POST http://localhost:8000/api/v1/ingest \
  -F "file=@report.pdf" \
  -F "chunking_strategy=layout_aware" \
  -F "embedding_model=minilm" \
  -F "engine=fast"
POST /api/v1/query Full Query + Gemini Synthesis

Embed → cosine search → Gemini synthesis. Returns full JSON response with generated_answer and cache_hit.

curl -X POST http://localhost:8000/api/v1/query \
  -F "query=What is the total revenue?" \
  -F "embedding_model=minilm" \
  -F "top_k=5"
POST /api/v1/query/stream ⚡ SSE Streaming

Same as /query but streams Gemini tokens via Server-Sent Events. Emits token, meta, sources, and done events.

curl -X POST http://localhost:8000/api/v1/query/stream \
  -F "query=What is the gross margin?" \
  -F "embedding_model=minilm" \
  --no-buffer
POST /api/v1/reset Reset Vector Store

Clears all vectors and metadata from LanceDB. Irreversible.

curl -X POST http://localhost:8000/api/v1/reset
