REST API Endpoints

Production endpoints for microservice integration. Use these endpoints from Python, Node.js, cURL, or any HTTP client.

POST /api/v1/extract
Raw Extraction (JSON / Markdown)

Extracts layout-preserving text and tables from any uploaded PDF without vectorization.

curl -X POST http://127.0.0.1:8000/api/v1/extract \
  -F "file=@document.pdf" \
  -F "engine=hybrid" \
  -F "output_format=json"
POST /api/v1/ingest
RAG Vector Ingestion

Runs the full 5-stage pipeline: Parse → Chunk → Embed → Attach Metadata → Store in Vector DB.

curl -X POST http://127.0.0.1:8000/api/v1/ingest \
  -F "file=@financial_report.pdf" \
  -F "chunking_strategy=layout_aware" \
  -F "embedding_model=minilm" \
  -F "engine=fast"
POST /api/v1/query
Semantic Search & Retrieval

Embeds the search query, performs cosine similarity search on the vector index, and returns top-k matching passages.

curl -X POST http://127.0.0.1:8000/api/v1/query \
  -F "query=What is the total revenue for Q3?" \
  -F "embedding_model=minilm" \
  -F "top_k=5"
POST /api/v1/reset
Reset Vector Store

Clears all vectors and metadata to restart from a clean state.

curl -X POST http://127.0.0.1:8000/api/v1/reset
